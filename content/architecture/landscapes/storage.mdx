This landscape is a **catalog of products**, not a 65th lesson. PostgreSQL is the default primary on the explorer. DynamoDB is a selectable alternative primary. Redis is the default derived cache hop. MySQL, MongoDB, Cassandra, OpenSearch, and S3 appear as property summaries until later phases add deep dives.

Authoritative vs derived:

- **Authoritative:** PostgreSQL (or DynamoDB if selected), S3 object bytes once PUT is acknowledged.
- **Derived:** Redis, read replicas, CDN, OpenSearch, observability, outbox/Kafka copies of already-committed rows.

Synchronous edges wait. Asynchronous edges (WAL ship, outbox, workers, telemetry) return before the sink commits. Failover of the primary is a named walkthrough: not instantaneous, not lossless under async replicas, not transparent to clients.
